# Analytics Dashboard

A modern and fully responsive analytics dashboard designed to simulate a real-world data environment.

Built with a focus on clean UI, smooth interactions, and practical features like search, notifications, and data export.

---

## Live Demo

 [https://analytic-dashboard.vercel.app](https://analytic-dashboard-mu.vercel.app)

---

## About the Project

This is a front-end analytics dashboard that replicates a real SaaS admin panel.

It allows users to visualize metrics, explore transaction data, and interact with UI elements such as search, notifications, and charts.

This project demonstrates strong skills in UI design, layout structuring, and dynamic JavaScript functionality.

---

## Features

* KPI cards with animated values
* Interactive charts (line, bar, doughnut)
* Real-time search with debounce
* Notification system with clear action
* Export data to CSV
* Fully responsive layout
* Modern dark UI with design system
* Smooth animations and transitions

---

## Technologies Used

* HTML5
* CSS3 (Custom Design System + Responsive Layout)
* JavaScript (Vanilla JS)
* Chart.js (for data visualization)
* Vercel (deployment)

## Key Functionalities

### Search System

Implements a debounced search to filter transactions dynamically based on:

* Name
* Email
* Channel
* Status

---

### CSV Export

Users can export transaction data into a CSV file with a single click.

---

### Notifications

Interactive notification system with badge counter and toast feedback.

---

### Data Visualization

Includes multiple chart types to simulate real analytics:

* Line chart (performance)
* Bar chart (comparison)
* Doughnut chart (distribution)
